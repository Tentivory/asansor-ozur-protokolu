# Asansör Özür Protokolü

Bu depo, modern mimarinin en ihmal edilmiş diplomatik aktörünü ele alır: asansör.

Asansör sizi bir kattan diğerine taşır. Bu sırada sizin zamanınızı, dengenizi ve bazen onurunuzu kullanır. Karşılığında standart bir „ding” sesi verir. Bu yetersizdir. Bu depo, kat farkına göre resmi, abartılı ve tamamen işe yaramaz bir özür metni üretir.

## Neden var?

Çünkü birisi “boş repo açma” dedi. Biz de boş bırakmadık. İçine bir protokol koyduk. Protokol çalışıyor. Dünya değişmiyor. İkisi de tasarım kararıdır.

## Kurulum

Python 3 yeter. Bağımlılık yok. Asansör de yok. Sadece özür var.

```bash
python asansor.py --nereden 1 --nereye 7 --ad Ahmet
```

Aynı katta kalırsanız protokol sizi azarlar. Çünkü asansör boşuna çağrılmıştır ve asansörler küskündür.
